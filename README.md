# Portfolio Project

This project is a static personal portfolio website built with HTML, CSS, and JavaScript.

## Structure

```text
PORTFOLIO/
├── index.html
├── README.md
├── css/
│   ├── animations.css
│   ├── components.css
│   ├── layout.css
│   ├── main.css
│   ├── reset.css
│   ├── typography.css
│   └── variables.css
├── data/
│   └── projects.json
├── images/
├── js/
│   ├── animations.js
│   ├── contact.js
│   ├── main.js
│   ├── navigation.js
│   ├── projects.js
│   └── utils.js
└── .git/
```

## How to run

Open `index.html` directly in a browser, or serve the project with a local HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
