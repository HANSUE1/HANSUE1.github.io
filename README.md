# Portfolio Project

This project is a static personal portfolio website built with HTML, CSS, and JavaScript.

## Structure

```text
PORTFOLIO/
├── index.html
├── README.md
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       └── main.js
└── .git/
```

## How to run

Open `index.html` directly in your browser, or serve the folder with a local HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
