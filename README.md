# Portfolio Project

This project is a static personal portfolio website built with HTML, CSS, and JavaScript.

## Structure

```text
PORTFOLIO/
├── index.html
├── README.md
├── css/
│   ├── main.css
│   ├── _variables.css
│   ├── _reset.css
│   ├── _typography.css
│   ├── _layout.css
│   ├── _components.css
│   └── _animations.css
├── data/
│   └── projects.json
├── images/
│   └── .gitkeep
├── js/
│   ├── main.js
│   ├── utils.js
│   ├── navigation.js
│   ├── animations.js
│   ├── projects.js
│   └── contact.js
└── .kilo/
```

## How to run

Open `index.html` directly in a browser, or serve the project with a local HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
