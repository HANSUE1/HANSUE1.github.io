# Hans Santos — Portfolio

Portfolio of Hans Curt Austin C. Santos, Computer Science student at National University (Digital Forensics). Live at https://hansue1.github.io/

Built with plain HTML, CSS, and JavaScript. Two parts (the opening name title and the Archive's glass folders) are React islands built with Vite; its output is committed, so the site itself still needs no build to run.

## Run locally

Open `index.html` in a browser, or serve this folder with Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

### Editing the React island

The React islands use React + TypeScript + Tailwind v4, set up for shadcn (`components.json`, components in `src/components/ui`, the `@/` alias pointing at `src/`). After changing anything in `src/`:

```bash
npm install        # once
npm run build      # type-checks, then writes js/react/islands.js and islands.css
```

Commit `js/react/` along with your `src/` changes: GitHub Pages serves the built files as they are. `npm run watch` rebuilds on every save while you work. Tailwind runs without its reset (preflight) and with a `tw:` prefix (`tw:flex`), so it never touches the hand-written CSS. Add shadcn components with `npx shadcn@latest add <name>`.

## Structure

```
index.html                     page markup, meta tags, JSON-LD
favicon.svg
css/main.css                   tokens → base → sections → responsive breakpoints
css/splash.css                 opening splash (aurora + name) and its fade-out
css/components/                styles for the components below
js/main.js                     nav highlighting, back-to-top, article dialog, contact form, component setup, GSAP motion
js/splash.js                   splash timing: hold, skip on click/key/scroll, fade out, then start the hero motion
js/components/glass-icons.js   GlassIcons: Tools section icons (WebGL glass, CSS fallback)
js/components/reflective-card.js  ReflectiveCard: brushed-metal profile card
js/components/soft-aurora.js   SoftAurora: aurora band behind the splash
images/                        WebP photo and project screenshots
src/components/ui/             shadcn-style UI components (glyph-portal.tsx, glass-folder-cards.tsx, Iridescence.jsx; unchanged from their sources)
src/components/name-portal.tsx the opening title: GlyphPortal set up with the name, colours and inside copy
src/components/archive-desk.tsx  the Archive's three folders, filled from the page's project and article cards
src/main.tsx                   bundle entry: loads every island below
src/islands/portal.tsx         mounts the title into #name-portal once the Poppins face is ready
src/islands/archive.tsx        mounts the Archive into #archive-desk
js/react/                      built island (generated by `npm run build`; do not edit)
```

The files in `js/components/` are plain-JavaScript ports of [React Bits](https://reactbits.dev) components (JS + CSS variant). Their shaders and helpers are the original source unchanged; only the part that replaced React is rewritten, so each one is set up with a function call (`GlassIcons(el, options)`, `ReflectiveCard(el, options)`, `SoftAurora(el, options)`) that takes the same options as the React props. A React component that should run as-is (like the glass folders) goes in `src/` instead and mounts as an island.

Layout breakpoints: base styles are the tablet layout (561–820px); `≤560px` is mobile; `≥821px` pins the profile card on the left and puts sections in a right-hand rail, with a compact card on short screens (`max-height: 860px`, tighter still at `730px`).

## Editing

- **Content** lives in `index.html`: profile card with the GitHub contributions graph below it (its username and time zone are `GITHUB_USER` and `GITHUB_TIME_ZONE` in `js/main.js`), hero, projects, experience, tools, soft skills, articles (`data-copy` holds an article's full text) and contact form.
- **Soft skills**: each `.skill` item's `style="--value: 75"` sets its level (0–100); keep the visible `75%` text in step with it.
- **Archive folders**: Projects and Writing are filled from the `.project-card` and `.thought-card` elements, so a new project or article appears in its folder automatically. Folder options (labels, art, menus) are in `src/components/archive-desk.tsx`.
- **Contact email**: `CONTACT_EMAIL` at the top of `js/main.js`. The form has no backend; it opens the visitor's email app.
- **Component options** (icon size, card tilt, colors): the `GlassIcons(...)` and `ReflectiveCard(...)` calls in `js/main.js`, and the `SoftAurora(...)` call in `js/splash.js`.
- **Cache busting**: after changing a CSS or JS file, bump the `?v=` number on its tag in `index.html`. GitHub Pages lets browsers cache files, so without it visitors (and you) can keep seeing the old version.

## Behaviour

The first visit in a browser tab opens on a splash: a SoftAurora band (site orange and cyan) behind the name, held for 4.5s (or until a click, key press or scroll) and then faded out to the page, at which point the hero entrance plays. An inline script in `<head>` decides whether to show it (`sessionStorage` key `introSeen`); to see it again, open the site in a new tab. If `js/splash.js` fails to load, `css/splash.css` still fades the splash out after 6s.

The Tools section uses glass icons: each link in `#tool-icons` holds an inline SVG glyph, its label text, and a `data-color` plate color. The profile card (`#profile-card`) is a ReflectiveCard holding the photo, name, role and social links; its colors are also set in `css/main.css`, so it is styled before its script runs.

The soft-skills meters are 20 ticks drawn by CSS from `--value`; with GSAP they light up tick by tick while the percentage counts up as each row scrolls in, and hovering a row sweeps a highlight across its meter. The site runs in three stages: landing page (the splash) → dev title → portfolio, joined by plain fades: the splash fades out and the title fades in after it (`css/splash.css`, `.portal-shell` in `css/main.css`); the title fades out and the hero fades in as you scroll between them (scrubbed GSAP fades in `js/main.js`), reversing on the way back up. While the dev title still covers most of the screen, `initTitleStage` in `js/main.js` puts `title-stage` on `<html>`, which hides the nav, the pinned profile card and the back-to-top button; as the title scrolls off they return and the profile card plays its entrance.

The dev title is a GlyphPortal: "Software developer", on two lines, cut out of a live React Bits Iridescence surface (`src/components/ui/Iridescence.jsx`, the JS + CSS variant, typed by `Iridescence.d.ts`), which follows the pointer and swirls on click. The word is `TITLE_WORD` in `src/components/name-portal.tsx`; a `\n` in it starts a new line. Hovering a letter (or the arrow keys) picks which one to enter; scrolling flies the camera into that letter until the field fills the screen and the copy inside it appears, then the hero follows, whose entrance plays as it scrolls into view. With reduced motion it is a static title and panel; without WebGL the surface falls back to a flat pale chrome; without JS, the words in plain text.

The Archive's three glass folders lean open on hover, fan their files out on click, and close on Escape or a click outside. Projects (smoked glass) holds each project's screenshot linked to its repository and a `···` menu with all repositories; Writing (milk glass) holds the articles, which open in the article dialog; Studies holds generated artwork, and its `+` key drops a newly painted study into the folder.

The section navigation highlights the current section, article cards open a reading dialog, the contact form prepares an email via `mailto:`, and a back-to-top button appears on scroll. Motion uses GSAP + ScrollTrigger (loaded from jsDelivr with integrity hashes); without them, or with reduced motion enabled, the page renders fully static. Everything is reachable by keyboard (skip link, visible focus rings).
